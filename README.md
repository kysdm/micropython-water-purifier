# ESP32-S3 净水器固件（MicroPython）

基于 **MicroPython + asyncio** 的 RO 反渗透净水器控制固件，运行于 **ESP32-S3** 开发板。

主要功能：

- 制水自动控制（低压/高压开关状态机）
- RO 膜强制冲洗、开机冲洗
- 纯水泡膜（洗膜）自动流程（TDS 达标/超时退出）
- 双通道 TDS / 水温监测（UART 传感器）
- 0.96 寸 SSD1306 OLED 中文界面（128×64，I2C）
- OLED 防烧屏：像素偏移 + 空闲自动熄屏 + 亮度控制
- 内置 Web 管理服务器（端口 80）：滤芯状态、参数设置、WiFi 配置、日志下载
- WiFi 自动连接/断线重连，NTP 自动校时
- 断电时间备份（软件近似时钟），离线也能启动
- 双核并行：阻塞硬件操作（OLED/TDS/WiFi）运行在第二核线程

## 硬件接线

接线如下：

| 外设 | 引脚 | 说明 |
|---|---|---|
| 高压开关 | GPIO4（上拉输入） | 0 = 压力未达标（正在制水）；1 = 压力达标（水龙头关闭） |
| 低压开关 | GPIO5（上拉输入） | 1 = 进水压力不足（缺水） |
| 压力桶进水电磁阀 | GPIO11（输出） | |
| 压力桶出水电磁阀 | GPIO12（输出） | |
| 增压泵 | GPIO9（输出） | |
| 废水阀 | GPIO10（输出） | |
| 进水电磁阀 | GPIO13（输出） | |
| TDS 传感器 | UART1：TX=GPIO17，RX=GPIO18，9600bps | 双通道协议 |
| OLED（0.96 寸） | SoftI2C：SDA=GPIO1，SCL=GPIO2 | SSD1306 128×64 |
| RGB LED | GPIO48 | WS2812B 单灯 |

RGB LED 颜色含义：

| 状态 | 颜色 |
|---|---|
| 制水 | 紫色 (199,18,184) |
| 冲洗 RO 膜 | 黄色 |
| 缺水 | 红色 |
| 纯水泡膜 | 绿色 |
| 空闲 | 熄灭 |

## 烧录与部署

1. **烧录 MicroPython 固件**（仅首次或升级固件时需要）：
   - 工具任选：esptool（命令行）、Thonny、VS Code MicroPico 插件；
   - 选择与板子匹配的固件（ESP32-S3 系列，注意 8MB/16MB flash 版本）。esptool 示意：
     ```bash
     esptool.py --port /dev/ttyUSB0 erase_flash
     esptool.py --port /dev/ttyUSB0 write_flash -z 0x0 ESP32S3-<固件版本>.bin
     ```
2. **同步代码到设备**：
   - VS Code + **MicroPico** 插件（`.vscode` 为本地编辑器配置，需按需自行创建，不随项目提供）；
   - 命令行推荐 `mpremote`（支持递归目录）：
     ```bash
     mpremote cp -r lib :/lib
     mpremote cp boot.py main.py config.py pins.py water.py oled.py web.py wifi.py ntp.py log.py time_utils.py tds.py countdown.py timer.py watchdog.py cartridge_usage_time.py threadsafe_context.py font.py ssd1306.py ws2812b.py :/
     ```
   - ⚠️ 不要直接 `mpremote cp -r . :`：会把本地 `config.json`（含 WiFi 密码）、`logs/`、`.history/` 一并上传覆盖设备；`ampy` 不支持目录递归，无法同步 `lib/`。
3. **首次配置 WiFi**（设备没有 AP 模式，默认 WiFi 连不上时将无法通过 Web 配置，二选一）：
   - **预置方式（推荐）**：在电脑上写好 `config.json`（含真实 WiFi 与 `web_password`）后随代码一起同步到设备根目录；
   - **热点方式**：先用手机/路由器开一个名为 `esp32`、密码 `12345678` 的热点，再给设备上电，待其连上后访问 `http://<设备IP>/wifi` 修改（Web 需登录：用户名 `admin`，密码默认 `admin`，见 [Web 管理](#web-管理)）。
4. **首次上电**：找不到有效 config.json 时自动生成默认配置（WiFi `esp32`/`12345678`，Web 密码 `admin`）；NTP 同步失败也会以本地近似时间继续启动，不影响部署。
5. **运行时文件**：`config.json`（配置）、`logs/`（日志）、`time_state.txt`（时间备份）均由设备在运行时自动生成——首次上电自动创建默认配置，无需手动提供。

## 启动流程

设备开机后的启动顺序：

1. **恢复断电前时间**：若保存有时间备份，先用近似时间恢复时钟（误差 = 断电时长）；
2. 启动日志轮换、日志刷盘、**每小时时间备份**任务；
3. 连接 WiFi（最多等待约 5 分钟）；
4. **NTP 校时**：尝试 2 次；失败不再阻塞，以本地近似时间继续启动，之后每 10 分钟自动重试；
5. 初始化 OLED 静态界面；
6. 启动后台任务：
   - 滤芯使用时间刷新（每 60 秒）
   - TDS / 水温刷新（每 1 秒）
   - WiFi 状态监控（每 30 秒，断线自动重连）
   - NTP 定时同步（每天 4 点校准；失败则 10 分钟重试）
   - Web 服务器
   - OLED 像素偏移 / 空闲自动熄屏（防烧屏）
7. 开机冲洗 RO 膜（18 秒）；
8. 进入制水主循环（0.5 秒轮询压力开关）。

## 制水与冲洗逻辑

设备按以下规则自动控制制水与冲洗：

| 条件 | 动作 |
|---|---|
| 低压开关 = 1（缺水） | 停止制水，停止强制冲洗任务，等待进水恢复（红色灯 + "缺水"） |
| 高压开关 = 0 且未在制水 | **开始制水**：开进水阀/压力桶进水阀/增压泵，关压力桶出水阀，紫色灯 |
| 高压开关 = 1 且正在制水 | **停止制水**：关闭全部阀门/泵，启动强制冲洗任务 + 纯水泡膜倒计时 |

**强制冲洗**：仅当累计制水运行时间达到设定值（默认 30 分钟）时执行，废水阀脉冲开合 3 次，完成后重置计时器。

**开机冲洗**：每次开机冲洗 18 秒，期间进水压力不足则提前中止。

**状态迁移图**：

```mermaid
stateDiagram-v2
    [*] --> 空闲: 开机初始化（含 18 秒开机冲洗）
    空闲 --> 制水: 高压开关 = 0（用户取水）
    制水 --> 空闲: 高压开关 = 1（关水）
    制水 --> 缺水: 低压开关 = 1（进水不足）
    缺水 --> 空闲: 进水恢复
    空闲 --> 冲洗: 关水后自动启动（累计运行达标）
    冲洗 --> 空闲: 冲洗完成（约 9 秒）
    空闲 --> 洗膜: 倒计时结束（30 秒等待 + 倒计时时间）
    洗膜 --> 空闲: 废水 TDS ≤ 目标 或 超时
    洗膜 --> 制水: 高压开关 = 0（用户重新取水）
```

> 说明：`冲洗` 与 `洗膜` 均在"停止制水"后由后台任务并发启动；`冲洗` 仅在累计制水运行时间达标时执行，否则直接跳过；屏幕上的"超时/完成"是洗膜结束时的显示状态，之后回到空闲。

## 纯水泡膜（洗膜）

停止制水后自动进入洗膜流程（提高 RO 膜寿命/脱盐率）：

1. **等待 30 秒**（期间若重新制水则取消）；
2. **倒计时**：默认 45 秒，屏幕显示剩余时间；
3. **泡膜**：打开压力桶出水阀，让纯水回流浸泡 RO 膜；
   - 先等待首批 TDS 数据就绪（最多 30 秒，防止初值 0 误判）；
   - 当**废水 TDS ≤ 目标值**（默认 10）→ "完成"；
   - 或运行超过设定时间（默认 5 分钟）→ "超时"；
   - 或用户重新取水制水（高压开关 = 0）→ 立即退出。

**倒计时显示规则**：纯数字，不带单位——

| 剩余时间 | 显示 | 刷新频率 |
|---|---|---|
| ≥ 1 分钟 | 分钟数（向上取整，如 `2`） | 每分钟变化一次 |
| < 1 分钟 | 秒数（如 `59`） | 每秒变化一次 |

通过刷新频率即可区分数字是分钟还是秒。

## OLED 界面与防烧屏

**常显布局**：

- 左侧：PP / UDF / CTO / RO / T33 五级滤芯使用天数；
- 右侧：纯水 TDS、废水 TDS、温度、状态（空闲/制水/缺水/冲洗/洗膜/超时/完成）或倒计时数字。

**防烧屏机制**（OLED 有机发光像素会因长期固定显示而老化，不可逆）：

- **像素偏移**：画面每 5 分钟在 2px 范围内循环平移，均摊固定元素的像素负载；
- **空闲自动熄屏**：无制水等运行状态且空闲超过 5 分钟后，屏幕自动关闭（像素完全不发光）；
- **运行状态点亮**：制水/冲洗/洗膜/缺水时自动点亮屏幕并保持，倒计时期间也保持点亮；
- **亮度控制**：默认亮度约 30%，降低老化速度。

**注意**：画面偏移 1~2px 时右侧/下侧边框会被裁剪，属正常现象。

## Web 管理

设备内置 Web 管理服务器（端口 80）：

| 路径 | 功能 |
|---|---|
| `/` | 主菜单 |
| `/status` | 传感器状态、滤芯使用天数、**重置滤芯**、倒计时/TDS/泡膜超时/强制冲洗时间设置（GET 查看，POST 修改） |
| `/wifi` | WiFi 名称/密码配置（密码页面与日志均掩码显示，仅保留首尾 2 位） |
| `/logs` | 日志文件列表（名称 + 大小） |
| `/logs/<file>` | 下载指定日志文件（仅允许 .txt，防路径穿越） |

实现细节：

- 🔒 **访问认证**：所有页面需要 HTTP Basic Auth（用户名 `admin`，密码为配置项 `web_password`，默认 `admin`）；首次访问浏览器会弹出登录框，密码错误返回 401；
- **修改密码**：在 `/wifi` 页面底部"修改 Web 访问密码"表单修改（4~32 位），立即生效无需重启；也可直接编辑设备上的 `config.json`；
- POST 表单参数已做 URL 解码（支持中文、`+`、`%`）；
- 设置值有范围钳制（见 [配置说明](#配置说明)）；
- ⚠️ Basic Auth 为局域网明文传输（base64），可防止误访问，但不足以抵御抓包窃听；请仅在可信内网使用。

## 配置说明

设备配置保存在 `config.json`，字段如下：

| 字段 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| `wifi_ssid` | esp32 | 1~32 字符 | WiFi 名称（不支持中文） |
| `wifi_password` | 12345678 | 8~63 字符 | WiFi 密码 |
| `web_password` | admin | 4~32 字符 | Web 管理访问密码（Basic Auth，/wifi 页面可修改） |
| `tds` | 10 | 5~30 | 纯水泡膜目标废水 TDS（ppm） |
| `countdown_time` | 45 | 1~3600 | 洗膜倒计时时长（秒） |
| `pure_water_ro_clean_timeout` | 5 | 1~10 | 泡膜最长运行时间（分钟） |
| `ro_force_clean_time` | 30 | 1~60 | 累计制水达到该分钟数后强制冲洗 RO 膜 |
| `pp` / `cto` / `udf` / `ro` / `t33` | 时间戳 | — | 各级滤芯最近一次重置的时间戳（用于计算使用天数） |

> 滤芯时间戳由系统在"重置滤芯"时自动写入，无需手动修改。

## 日志系统

- 日志先写入内存缓冲，**每 15 秒刷入 flash**（`/logs/log.txt`），断电最多丢失 15 秒日志；
- 文件达到 **200 KB** 自动轮换为 `log_<时间戳>.txt`，**最多保留 5 份**；
- 每条日志带状态前缀，如：
  `[2025-01-01 12:00:00.000000] - [进水√|制水√|压力桶进水×|压力桶出水×|纯水TDS:5|废水TDS:150|累计运行:6m] - 开始制水.`
- 可通过 Web `/logs` 页面下载查看。

## 时间与断电备份

**校时**：

- NTP 服务器：`ntp.aliyun.com`（阿里云），时间自动按北京时间（UTC+8）显示；
- 每次同步成功自动把时间写入 flash 备份；
- 每天 4 点定时校准；若上次同步失败，则每 10 分钟重试。

**断电时钟**：

- ESP32-S3 无后备电池 RTC，**完全断电后时钟归零**（回到 2000-01-01 纪元）；
- 固件通过"软件近似时钟"解决：
  1. NTP 同步成功时 + 每小时一次，把 UTC 时间戳写入 `/time_state.txt`；
  2. 上电复位且时钟归零时，用 **上次保存值 + 开机已运行秒数** 恢复；
  3. 时间戳小于 1 年视为未同步，不保存/不恢复，避免污染有效备份；
- 近似误差 = 断电时长（+ 最多 1 小时备份间隔）；NTP 恢复后自动校准，滤芯天数等计算自动修正。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 断电重启后日志时间不对 | 断电期间时间无法保留；等 NTP 同步成功后自动校准（日志中会看到"同步时间成功"） |
| 离线断电后无法启动 | NTP 不可用时设备会以备份的近似时间启动，之后每 10 分钟重试同步 |
| 屏幕不亮 | 空闲超时（约 5 分钟无运行状态）自动熄屏属正常，运行状态会自动点亮；检查屏幕接线（SDA=GPIO1/SCL=GPIO2）；屏幕通信异常时系统会自动重连 |
| 屏幕出现轻微残影/边框缺失 | 防烧屏像素偏移导致 1~2px 裁剪，属正常 |
| 制水中屏幕突然熄灭 | 制水等运行状态下屏幕应保持点亮；如异常请检查固件版本 |
| Web 无法访问 | 确认设备已连 WiFi，访问 `http://<设备IP>`；日志中可查 `Web服务器启动成功`；浏览器会要求输入用户名 `admin` 与访问密码 |
| 忘记 Web 访问密码 | 编辑设备上的 `config.json`，删除或修改 `web_password` 字段后重启（删除则恢复默认 `admin`） |
| 日志文件很多 | 自动轮换机制最多保留 5 份，超出自动清理 |
